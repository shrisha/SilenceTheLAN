# App Store Listing (en-US)

## Name
SilenceTheLAN

## Subtitle
One-tap UniFi internet control

## Promotional text
Control your kids' internet with a tap. Pause or restore access instantly on your local UniFi network.

## Description
SilenceTheLAN gives parents a fast way to control internet access on UniFi networks.

Set up your firewall rules in UniFi once, then toggle access from your iPhone:
- One-tap block or allow
- Time-limited extensions (15m, 30m, 1h, 2h)
- Rules grouped by person
- Schedule-aware overrides with automatic restore

Built for privacy:
- Local network only
- No cloud account required in the app
- No remote relay service

Requirements:
- iOS 17.0+
- Compatible UniFi controller on the same network
- Local UniFi admin account
